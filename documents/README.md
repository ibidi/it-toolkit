# 📚 Dokümantasyon

Bu klasör, IT Toolkit projesinin dokümantasyon ve orijinal araçlarını içerir.

## 📁 İçerik

### original-tools/
Orijinal Python ve Batch scriptleri:

- **automation-scripts/** - Otomasyon araçları
- **network-tools/** - Ağ araçları
- **security-tools/** - Güvenlik araçları
- **system-tools/** - Sistem araçları

## 🔧 Orijinal Araçları Kullanma

### Python Araçları

```bash
# Gerekli kütüphaneleri yükle
cd documents/original-tools
pip install -r requirements.txt

# Herhangi bir aracı çalıştır
python network-tools/ip_scanner.py
python security-tools/hash_generator.py
```

### Batch Araçları (Windows)

```cmd
# Doğrudan çalıştır
automation-scripts\log_cleaner.bat
system-tools\temp_cleaner.bat
```

## 📖 Detaylı Kullanım

Detaylı kullanım bilgileri için `original-tools/KULLANIM.md` dosyasına bakın.
